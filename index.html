A few useful distinctions

Get your bearings.

What is Object-Oriented UX?

OOUX is an approach to organizing experiences around the meaningful objects in a domain, their relationships, their content, and the actions people can take. An Order, for example, remains an Order whether you encounter it in a list, a detail view, or a fulfillment flow.

Is this the modeling application?

This is the introductory site for Thinking in CARDS, previously called OOUX Tool. The example above is a small interactive illustration. It does not open or modify projects in the modeling application.

Do I need to know OOUX to explore this?

No. Start with the Objects tab in the example, then move through Relationships, Actions, and Representations. Each perspective explains a different part of the same commerce system.

Does the example save my changes?

The illustration uses predefined sample data and does not create a project or save personal information. Switching perspectives changes only what you see on this page.
